한 조종자가 2021년에 중고로 구입한 드론을 몇 년 만에 다시 꺼내 동네 공원에서 띄웁니다. 등록도 되어 있고, 배터리도 새로 샀고, 비행 자체에는 아무 문제가 없어 보입니다. 그런데 공원 관리자가 다가와 이 기체가 Remote ID 신호를 방송하고 있지 않다고 지적합니다. 조종자 입장에서는 억울할 수 있습니다 — 몇 년 전에는 이런 요건 자체가 없었으니까요. 하지만 Remote ID는 드론을 산 시점이 아니라 지금 비행하는 시점의 규정을 기준으로 적용되며, 대부분의 조종자가 이 사실을 실제로 단속을 겪고 나서야 깨닫습니다.

## Remote ID가 실제로 방송하는 정보

Remote ID는 흔히 "드론의 디지털 번호판"으로 설명되지만, 실제로 방송되는 데이터는 번호판보다 훨씬 많습니다: 기체 식별번호(일련번호 또는 세션 ID), 드론의 실시간 위치와 고도, 속도, 조종자 위치(또는 이륙 지점), 비상 상태 표시, 타임스탬프가 여기 포함됩니다. 이 정보는 인터넷이나 휴대폰 데이터 연결 없이, Wi-Fi 또는 블루투스로 근거리에 직접 방송됩니다 — 즉 클라우드 서버로 전송되는 게 아니라, 근처에 있는 사람이 전용 앱으로 직접 수신하는 방식입니다. 수신 가능 거리는 기체와 환경에 따라 다르지만 대체로 수백 미터에서 1마일 안팎으로 알려져 있어, 완전히 격리된 곳이 아니라면 공원의 다른 방문객이나 단속 인력이 충분히 잡아낼 수 있는 범위입니다.

## 세 가지 준수 방법, 그리고 각각의 함정

준수 방법은 세 가지입니다. 첫째, Remote ID가 내장된 표준 드론(대부분의 최신 기체)입니다. 둘째, 기존 드론에 별도의 방송 모듈을 부착하는 방법인데, 여기 흔히 간과되는 차이점이 있습니다 — 모듈 방식은 드론의 실시간 위치는 계속 보고하지만, 조종자 위치 대신 "이륙 지점"을 고정값으로 방송합니다. 비행 중 조종자가 이동해도 이 값은 갱신되지 않으므로, 실제 조종자 위치와 다른 정보가 계속 송출된다는 점을 알아둘 필요가 있습니다. 셋째는 FAA 인증 식별구역(FRIA) 내에서만 비행하는 방법으로, Remote ID 장비가 전혀 없는 기체(취미용으로 직접 제작한 드론 포함)는 이 방법 외에는 합법적으로 비행할 수 없습니다. 직접 제작한 드론은 원칙적으로 방송 모듈 방식을 인정받지 못하고 FRIA 준수만 가능하다는 점이 특히 자주 간과됩니다.

## 250그램 기준이 흔히 오해되는 이유

무게 0.55파운드(약 250g) 미만 드론은 순수 레크리에이션 목적으로만 비행한다면 등록 자체가 면제되고, 등록 의무가 없으니 Remote ID도 필요 없습니다. 하지만 이 예외는 무게가 아니라 등록 의무 여부에 걸려 있다는 점이 핵심입니다 — 같은 250g 미만 드론이라도 상업적 목적이나 Part 107 비행으로 조금이라도 성격이 바뀌면 등록이 의무화되고, 그 순간 Remote ID 요건도 함께 발생합니다. "가벼우니까 예외"라고 단순하게 기억했다가, 부동산 촬영이나 유료 작업에 같은 기체를 쓰면서 요건을 놓치는 경우가 실제로 자주 나옵니다.

## 흔한 오해: 실시간 추적이 아니다

Remote ID를 FAA가 모든 드론을 실시간으로 위성 추적하는 시스템으로 오해하는 경우가 많은데, 실제로는 근거리 로컬 방송 방식입니다. 일반 시민이든 법 집행기관이든 근처에서 수신 앱으로 직접 잡아야 정보를 볼 수 있으며, 자동으로 FAA 서버에 위치가 누적 저장되는 구조가 아닙니다. 이 구조를 모르면 방송 모듈의 배터리를 드론 배터리와 별개로 관리해야 한다는 점도 놓치기 쉽습니다 — 모듈 배터리가 방전되면 드론은 멀쩡히 날아도 Remote ID 신호는 끊기고, 이는 비행 중 발견되기 전까지 조종자가 인지하지 못하는 경우가 많습니다.

## 실전 체크리스트

- 본인 드론이 표준 내장형인지, 별도 모듈이 필요한지, FRIA 전용인지부터 확인하세요.
- 방송 모듈을 쓴다면 모듈 배터리를 비행 전 별도로 점검하세요 — 드론 배터리와는 완전히 별개입니다.
- 직접 제작한(홈빌트) 드론이라면 FRIA 밖에서는 합법적으로 비행할 방법이 없다는 점을 기억하세요.
- 250g 미만이라고 해도 상업적·업무 목적 비행이라면 등록과 Remote ID 요건이 모두 발생합니다.
- FRIA 경계는 생각보다 좁은 경우가 많으므로, 공원 전체가 아니라 정확한 구역 지도를 사전에 확인하세요.
- 이 사이트의 정보는 참고용일 뿐이므로, 비행 전 FAA의 최신 Remote ID 규정과 등록 상태를 직접 확인하세요.
