이 가이드는 미국을 기준으로 합니다. Remote ID는 FAA의 규정이며, 드론을 구입한 날이 아니라 실제로 비행하는 날을 기준으로 그 기체에 적용됩니다. 2021년에 등록해 둔 드론을 오랜만에 꺼내 공원에서 날리는 조종자도 구입 당시 상자에 적혀 있던 내용과 관계없이 지금의 규정을 따라야 합니다.

## 핵심 요약

- Remote ID는 등록이 필요하거나 이미 등록된 드론에 적용되며, 취미 비행, 업무용 비행, 공공안전 목적 비행을 가리지 않습니다.
- 준수 방법은 세 가지입니다. 표준 Remote ID 드론(Standard Remote ID drone)을 쓰거나, 방송 모듈(broadcast module)을 장착한 드론을 쓰거나, 방송 없이 FAA가 인정한 식별 구역(FRIA) 안에서만 비행하는 방법입니다.
- FAA 등록 안내 페이지에는 예외가 하나 있습니다. 0.55파운드(250그램 미만) 이하의 드론을 취미로 날릴 때는 등록하지 않아도 되며, 따라서 Remote ID와도 연결되지 않습니다.
- FAA의 재량적 단속 유예 기간은 2024년 3월 16일에 끝났기 때문에, 요건을 갖추지 못한 기체의 조종자는 이제 벌금이나 조종사 증명에 대한 조치를 받을 수 있습니다.
- 비행 전에 본인의 기체와 상황을 FAA에 직접 확인하세요. 이 글은 계획을 세울 때 참고하는 자료이며 법률 자문이 아닙니다.

## Remote ID가 실제로 방송하는 것

Remote ID는 흔히 디지털 번호판이라고 불립니다. FAA에 따르면 표준 Remote ID 드론은 고유 식별자(일련번호 또는 세션 ID), 드론의 위도, 경도, 기하학적 고도와 속도, 조종 장치의 위도, 경도, 기하학적 고도, 시각 표시, 비상 상태 표시를 방송합니다. 방송 모듈을 단 드론은 모듈의 일련번호, 드론의 위치와 속도, 이륙 위치, 시각 표시를 보냅니다. 두 경우 모두 이륙부터 전원이 꺼질 때까지 방송이 계속됩니다.

FAA는 이 정보를 다른 주체가 수신할 수 있다고 설명합니다. FAA, 법 집행기관, 그 밖의 연방 기관은 이 정보를 이용해 조종 장치의 위치를 파악하며, 공공안전 기관의 권한 있는 담당자는 FAA에 드론 소유자가 누구인지 문의할 수 있습니다. 세션 ID는 법 집행기관과 FAA가 일련번호와 연결할 수 있지만, 그 연결 정보는 일반에 공개되지 않습니다. FAA 페이지에는 사용하는 무선 기술이나 수신 거리에 대한 설명이 없으므로, 거리를 임의로 짐작하지 말고 기체의 사용 설명서를 확인하세요.

## 세 가지 준수 방법

첫 번째는 표준 Remote ID 드론으로, 제작 단계부터 방송 기능이 갖춰진 기체입니다. 두 번째는 방송 모듈(broadcast module)을 장착한 드론으로, 기체에 추가한 별도 장치이거나 소프트웨어 기능일 수 있습니다. 이 방식에서는 조종자가 비행 내내 드론을 눈으로 볼 수 있어야 합니다. 세 번째는 Remote ID 장비 없이 날리는 방법으로, 시야 내 비행(visual line of sight)일 때만, 그리고 FAA가 인정한 식별 구역(FAA-recognized identification area, FRIA) 안에서만 허용됩니다. FRIA는 지역 기반 단체나 교육기관이 신청할 수 있습니다. 작동 방식은 [FRIA 설명 가이드](/ko/guides/fria-explained)에서 확인하세요.

한 가지 차이는 눈여겨볼 만합니다. 방송 모듈은 조종 장치의 실시간 위치가 아니라 이륙 위치를 보고합니다. 따라서 비행 중에 이동하는 조종자는 표준 Remote ID 기체와 같은 방식으로 추적되지 않으며, 모듈이 보내는 데이터를 조종자의 현재 위치로 읽어서는 안 됩니다.

## 250그램 예외가 적용되는 방식

FAA 등록 안내 페이지에 따르면 대부분의 드론은 등록해야 하고, 예외는 무게가 0.55파운드(250그램 미만) 이하이면서 취미로 날리는 드론입니다. Remote ID는 등록을 따라갑니다. FAA는 FAA 등록 번호가 필요한 드론이라면 FRIA 안에서 비행하는 경우를 제외하고 Remote ID도 방송해야 한다고 밝힙니다. 자발적으로 등록한 드론도 Remote ID 규정의 적용을 받습니다.

중요한 것은 무게만이 아니라 어떻게 비행하느냐입니다. 예를 들어 유료 작업처럼 Part 107에 따라 쓰는 드론은 취미용 예외에 해당하지 않으며, 취미용으로 등록한 드론을 Part 107 비행에 쓸 수도 없습니다. 등록 비용은 5달러이고 유효 기간은 3년입니다. 취미용 등록은 보유한 모든 드론을 한 번에 포괄하지만, Part 107 등록은 기체마다 따로 합니다. 가벼운 드론이라도 업무 목적이 조금이라도 있다면 먼저 [Part 107 개요](/ko/guides/faa-part-107-explained)를 읽어 보세요.

## Remote ID는 방송이지 추적 피드가 아닙니다

FAA가 모든 드론을 실시간으로 따라간다고 생각하는 조종자도 있습니다. 하지만 이 규정은 근처의 수신기가 받을 수 있는 방송, 그리고 FAA와 법 집행기관이 그 데이터를 활용할 수 있는 능력을 중심으로 설계되어 있습니다. 누구나 비행 기록을 조회하는 서비스가 아닙니다. FAA 페이지에는 모듈의 전원이나 수신 거리에 대한 설명이 없으므로, 사용하는 모듈의 설명서를 읽고 매 비행 전에 전원과 설정을 점검하세요.

## 시행 시한과 단속

FAA의 Remote ID 페이지는 준수 기한을 2023년 9월 16일로 제시합니다. 이후 FAA는 재량적 단속 정책을 2024년 3월 16일에 끝낸다고 발표했습니다. FAA의 표현에 따르면 그날 이후 요건을 지키지 않는 운용자는 벌금은 물론 드론 조종사 증명의 정지 또는 취소에 직면할 수 있습니다. 규정은 바뀔 수 있으므로 현재의 내용은 FAA 사이트에서 확인하세요.

## 실전 체크리스트

- 내 기체가 표준 Remote ID 드론인지, 방송 모듈을 쓰는지, 아니면 FRIA 안에서만 날릴 수 있는지 확인하세요.
- 모듈을 쓴다면 매 비행 전에 전원과 설정을 점검하고, 드론을 시야에 두어야 한다는 점을 기억하세요.
- FRIA를 이용한다면 지도에 표시된 정확한 경계를 찾아보고, 비행이 그 안에 머무는지 확인하세요.
- 비행에 업무 목적이 조금이라도 있다면 가벼운 드론이라고 해서 예외라고 단정하지 마세요.
- 등록 상태와 등록 만료일을 확인하세요.
- 비행 전에 현재 규정을 FAA에 직접 확인하세요.

## 자주 묻는 질문

### 규정이 생기기 전에 산 드론도 Remote ID가 필요한가요?

등록이 필요하거나 이미 등록한 드론이라면 Remote ID 규정이 적용됩니다. FAA는 이전에 나온 기체에도 같은 세 가지 준수 방법을 제시합니다. 내장된 방송 기능, 방송 모듈, 또는 FRIA입니다.

### 다른 사람이 내 위치를 볼 수 있나요?

FAA는 다른 주체가 Remote ID 정보를 수신할 수 있다고 밝힙니다. 공공안전 담당자는 FAA에 소유자의 신원을 문의할 수 있지만, 세션 ID와 일련번호의 연결 정보는 공개되지 않습니다.

### 250그램 미만 드론도 Remote ID가 필요한가요?

FAA 등록 안내 페이지는 0.55파운드 이하의 드론을 취미로 날릴 때는 등록하지 않아도 된다고 설명합니다. FAA 등록 번호가 필요 없다면 등록에 따라붙는 Remote ID 요건도 적용되지 않습니다. 다만 그 드론을 Part 107에 따라 쓰거나 등록한 경우에는 규정이 적용됩니다.

### Remote ID는 등록과 같은 것인가요?

아닙니다. 등록은 기체에 FAA 번호를 부여하는 절차이고, Remote ID는 비행 중에 신원과 위치 데이터를 방송하는 것입니다. 둘은 연결되어 있어서, 등록 번호가 필요한 드론은 Remote ID도 방송해야 합니다.
