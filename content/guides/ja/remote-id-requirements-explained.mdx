このガイドは米国を対象としています。Remote IDはFAAの規則であり、ドローンを購入した日ではなく、実際に飛行させる日の規則が適用されます。2021年に購入して登録済みのドローンを久しぶりに取り出し、今日公園で飛ばすパイロットは、購入当時の箱に何と書かれていたかにかかわらず、現在の規則に従う必要があります。

## 要点

- Remote IDは、登録が必要なドローン、または登録されているドローンに適用されます。趣味の飛行、仕事での飛行、公共安全のための飛行のいずれも対象です。
- 準拠の方法は3つあります。Standard Remote IDドローン(Standard Remote ID drone)を使う方法、ブロードキャストモジュール(broadcast module)を搭載したドローンを使う方法、そしてFAAが認定した識別区域(FAA-recognized identification area、FRIA)の内側でのみ、発信なしで飛行させる方法です。
- FAAの登録ページには例外が1つ記載されています。重さが0.55ポンド以下(250グラム未満)のドローンを趣味で飛ばす場合は登録が不要で、そのためRemote IDの対象にもなりません。
- FAAの裁量的な執行猶予期間は2024年3月16日に終了しました。現在は、規則に適合しない機体のパイロットが罰金や操縦者証明書に対する措置を受ける可能性があります。
- 飛行前に、ご自身の機体と状況についてFAAで確認してください。このページは計画の参考資料であり、法的助言ではありません。

## Remote IDが実際に発信する情報

Remote IDは「デジタルのナンバープレート」とよく呼ばれます。FAAによると、Standard Remote IDドローンは、固有の識別子(シリアル番号またはセッションID)、ドローンの緯度・経度・幾何高度・速度、操縦装置(コントロールステーション)の緯度・経度・幾何高度、時刻の記録、緊急状態の表示を発信します。ブロードキャストモジュールを搭載したドローンは、モジュールのシリアル番号、ドローンの位置と速度、離陸地点、時刻の記録を送信します。どちらの場合も、発信は離陸からシャットダウンまで続きます。

FAAは、この情報を第三者が受信できると説明しています。FAA、法執行機関、その他の連邦機関はこの情報を使って操縦装置の位置を特定し、公共安全機関の権限を持つ担当者はドローンの所有者をFAAに照会できます。セッションIDは法執行機関とFAAがシリアル番号と結び付けられますが、その対応関係は一般には公開されていません。FAAのページには無線技術や到達距離の説明がないため、距離を思い込みで判断せず、お使いの機体の取扱説明書を確認してください。

## 準拠する3つの方法

1つ目は、発信機能を最初から備えて製造されたStandard Remote IDドローンです。2つ目は、ブロードキャストモジュール(後付けの機器、または機体に追加するソフトウェア機能)を備えたドローンです。この方法では、飛行中は常にドローンを目視できる状態でなければなりません。3つ目は、Remote ID機器なしで飛行させる方法で、目視内飛行に限り、かつFAAが認定した識別区域(FRIA)の内側でのみ認められています。FRIAは、コミュニティベースの団体や教育機関が申請できます。仕組みについては[FRIAの解説ガイド](/ja/guides/fria-explained)をご覧ください。

ここで注意したい違いが1つあります。モジュールが報告するのは、操縦装置のリアルタイムの位置ではなく離陸地点です。そのため、飛行中にパイロットが移動しても、Standard Remote IDの機体と同じようには追跡されません。モジュールのデータを、操縦者の現在位置と読み替えないでください。

## 250グラム以下の免除の仕組み

FAAの登録ページによると、ほとんどのドローンは登録が必要で、例外となるのは重さが0.55ポンド以下(250グラム未満)で、趣味として飛ばすドローンです。Remote IDは登録に連動しています。FAAは、FAAの登録番号が必要なドローンは、FRIAの内側で飛行させる場合を除き、Remote IDも発信しなければならないと述べています。自主的に登録したドローンも、Remote IDの規則の対象です。

重要なのは重さだけでなく、どのように飛ばすかです。有償の仕事など、Part 107のもとで使うドローンは趣味の例外には当たらず、趣味用として登録したドローンをPart 107のもとで使うこともできません。登録料は5ドルで、有効期間は3年です。趣味用の登録は手持ちのすべてのドローンをまとめて対象とし、Part 107の登録は機体ごとに行います。軽量なドローンに仕事での利用の予定が少しでもある場合は、先に[Part 107の概要ガイド](/ja/guides/faa-part-107-explained)をお読みください。

## Remote IDは発信であり、追跡配信ではない

FAAがすべてのドローンをリアルタイムで追跡していると考えている人もいます。しかし規則は、近くの受信機が拾える発信と、FAAや法執行機関がそのデータを扱える仕組みを中心に作られています。一般向けの飛行履歴サービスではありません。FAAのページはモジュールの電源や到達距離を説明していないため、お使いのモジュールの取扱説明書を読み、毎回の飛行前に電源と設定を確認してください。

## 期限と執行

FAAのRemote IDのページには、準拠期限が2023年9月16日と記載されています。その後FAAは、裁量的な執行方針を2024年3月16日に終了すると発表しました。FAA自身の表現によると、この日以降は、規則に従わない操縦者が罰金のほか、ドローン操縦者証明書の停止や取り消しを受ける可能性があります。規則は変わることがあるため、最新の内容はFAAのサイトで確認してください。

## 実践チェックリスト

- お使いの機体が、Standard Remote IDドローンか、ブロードキャストモジュールを使うものか、FRIAの内側でしか飛ばせないものかを確認します。
- モジュールを使う場合は、毎回の飛行前に電源と設定を確認し、ドローンを目視し続ける必要があることを忘れないでください。
- FRIAを使う場合は、地図上の正確な境界を調べ、飛行がその内側に収まることを確認します。
- 仕事の目的が少しでも含まれる飛行では、軽量なドローンだから免除されると思い込まないでください。
- 登録の状況と有効期限を確認します。
- 飛行前に、最新の規則をFAAで直接確認します。

## よくある質問

### 規則ができる前に購入したドローンにもRemote IDは必要ですか?

登録が必要な機体、またはご自身で登録した機体であれば、Remote IDの規則が適用されます。FAAは古い機体にも同じ3つの準拠方法を挙げています。内蔵機能、ブロードキャストモジュール、またはFRIAです。

### 自分の居場所を誰でも見られますか?

FAAは、Remote IDの情報を第三者が受信できると述べています。公共安全の担当者は所有者の身元をFAAに照会できますが、セッションIDとシリアル番号の対応関係は公開されていません。

### 250グラム未満のドローンにRemote IDは必要ですか?

FAAの登録ページによると、0.55ポンド以下のドローンを趣味で飛ばす場合は登録が不要です。FAAの登録番号が不要であれば、登録に連動するRemote IDの要件も適用されません。ただし、そのドローンをPart 107のもとで使う場合や、登録した場合には、規則が適用されます。

### Remote IDと登録は同じものですか?

いいえ。登録は機体にFAAの番号を付与する手続きで、Remote IDは飛行中に識別情報と位置情報を発信する仕組みです。両者は関連しており、登録番号が必要なドローンはRemote IDも発信しなければなりません。
