空港は、ドローン飛行で最も失敗の代償が大きい場所です。ミスが有人航空機との衝突の危険につながりかねないためです。このガイドでは米国の手順を扱います。他の国では規則が異なるため、飛行する場所の規制当局に確認してください。

## 要点

- 「空港の近く」は、目測できる固定の距離ではなく、空域によって定義されます。飛行する地点そのものの空域クラスを確認してください。
- クラスB、C、D、および空港のために指定されたクラスE空域の地表面区域では、Part 107の操縦者もレクリエーション目的の操縦者も、事前にATC(航空管制)の許可が必要です。
- 特定の時間、高度、場所について許可を申請し、UASファシリティマップに示された高度以下にとどまってください。
- 許可が対象とするのは空域だけです。TFR、NOTAM、気象は自分で確認してください。
- 衝突を避ける責任を負うのは有人機ではなく操縦者自身です。航空機が接近したら着陸してください。

## ステップ1:空港に対する実際の位置を確認する

「空港の近く」は、見た目より遠いことがよくあります。管制空域は、空港とその進入・出発経路を中心に設けられているため、方向によって数マイルも広がる一方、ほとんど広がらない方向もあります。たとえばAIMは、典型的なクラスCの配置を、半径5海里の中心部と10海里の外側の棚状の部分で構成されるものと説明しており、クラスDは空港ごとに個別に設計されます。目測ではなく、FAAが承認したアプリや航空図を使い、自分が立っている場所とは異なる場合もある、ドローンが実際に飛ぶ地点を地図で確認してください。

## ステップ2:空域クラスを確認する

空港の近くだと分かったら、空域クラス(B、C、D、または地表面のE)を確認します。これによって、許可が必要かどうか、またどの手続きになるかが決まります。各クラスは[米国の空域クラス](/ja/guides/understanding-us-airspace-classes)の解説で説明しています。つまずきやすい点が2つあります。

- クラスDは、時間限定の場合があります。管制塔が閉まっているときは、クラスEの地表面区域またはクラスGに戻ることがあるため、飛行する予定の時刻にどのクラスが適用されるかを確認してください。
- 管制塔のない空港でも、クラスEの地表面区域を持つことがあり、その場合はクラスDと同様に許可が必要です。

## ステップ3:必要な場合は許可を得る

空港付近のほとんどの管制空域では、FAAが承認したUASサービスサプライヤーを通じて、LAANCで許可を申請します。一般的な上限まで飛行できると決めつけず、飛行する予定の高度、場所、時間を指定してください。

- Part 107の操縦者もレクリエーション目的の操縦者も、機体を登録し、資格要件(Part 107ではリモートパイロット証明書、レクリエーションではTRUSTテスト)を満たしたうえで、ほぼリアルタイムのLAANC許可を利用できます。
- その格子の区画のUASファシリティマップの高度以下で飛行してください。上限がゼロの場合は、施設との調整なしには飛行が認められません。
- 空港がLAANCに対応していない場合は、手動のFAA DroneZoneの手続きになります。FAAによれば、これらの申請は手作業で処理され、従来は最大8週間かかっているため、十分に余裕を持って計画してください。
- Part 107の操縦者は、マップの上限を超える高度について、400フィートまでの追加の調整を求めることができます。レクリエーション目的の操縦者はできません。

詳細は[LAANCとは何か、どのように機能するか](/ja/guides/what-is-laanc-and-why-it-matters)を参照してください。LAANCが提供するのは空域の許可だけで、他のすべての規則も引き続き守る必要があります。

## ステップ4:TFRとNOTAMを確認する

通常の空域クラスとは別に、TFRによって、ある区域での飛行が一時的に禁止または制限されることがあります。特定の日付と場所について、FAAのTFR情報を確認し、[TFRの解説](/ja/guides/temporary-flight-restrictions-tfr-explained)と[NOTAMの仕組み](/ja/guides/notam-explained)も読んでください。FAAは、LAANCの許可を得ていても、NOTAMと気象状況は必ず確認しなければならないとしています。

## ステップ5:飛行中も警戒を怠らない

FAA自身の指針では、ドローンの運用者が有人機を避ける責任を負います。有人機のパイロットは、小型のドローンが危険なほど近づくまで気づけないことがよくあります。許可を持っているかどうかにかかわらず、ドローンを目視内に保ち、航空機の姿や音に注意し、接近してきたらすぐに着陸できるようにしてください。視覚補助者として協力者がいると、これが容易になります。目視の規則は、[VLOSとBVLOSの解説](/ja/guides/vlos-bvlos-explained)で扱っています。

## 空港付近の飛行前チェックリスト

| 確認項目 | 確認する内容 |
|---|---|
| 位置 | 自分の位置だけでなく、ドローンの地図上の位置 |
| クラス | B、C、D、Eの地表面区域、またはG。時間限定の場合は管制塔の運用時間 |
| 許可 | この時間、場所、高度についてのLAANCまたはDroneZoneの承認 |
| 上限高度 | 予定高度がファシリティマップの値以下であること |
| TFRとNOTAM | 日付と区域について、有効なものがないこと |
| 航空機 | 有人機が接近したらすぐに着陸する計画 |
| 登録とRemote ID | 機体が登録され、Remote IDの要件を満たしていること |
| 書類 | 許可の保存またはスクリーンショット、必要に応じた操縦者の証明 |

FlyDroneMapの[ダッシュボード](/ja)では、米国の場所のファシリティマップの上限高度を簡易的な参考として確認でき、[米国の規制ページ](/ja/regulations/us)には主な規則をまとめています。どちらも、実際の許可の代わりにはなりません。

## よくある間違い

- 空港までの見た目の距離に頼ること。空域の境界は、道路やフェンスに沿ってはいません。
- 上限高度で許可を申請したのに、ドローンが上がれるからと、それより高く飛ばすこと。
- 管制塔が閉まっていることを許可と見なすこと。時間限定のクラスDがクラスEやGになることはありますが、決めつけずに確認してください。
- LAANCで承認されたからと、TFRの確認を省くこと。許可が対象とするのは空域だけです。
- 習慣で管制塔に電話すること。許可で特に求められない限り、ドローンの操縦者は飛行前に管制塔へ連絡する必要はありません。

## よくある質問

### 空港からどのくらい近いと近すぎるのですか?

どこでも通用する単一の距離はありません。重要なのは、その地点がクラスB、C、D、またはクラスEの地表面区域にあるかどうかです。そのため、距離を測るのではなく、空域を確認します。

### 管制塔のない小さな空港でも、LAANCは必要ですか?

その空港にクラスEの地表面区域(またはクラスD)があるかどうかによります。ある場合は許可が必要です。その場所の空域がクラスGなら、ATCの許可は不要ですが、有人機を避ける責任は残ります。

### 空港がLAANCに対応していない場合は?

FAA DroneZoneで手動の手続きを使い、十分な余裕を見てください。許可を得るまで、その管制空域で飛行してはいけません。

### 許可があれば、安全に飛べるのですか?

いいえ。許可は空域への進入を認めるだけです。TFR、NOTAM、気象の確認も必要で、有人機には引き続き進路を譲る必要があります。
