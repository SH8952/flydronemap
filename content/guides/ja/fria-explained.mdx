FRIA(FAA-Recognized Identification Area)とは、米国においてRemote IDを発信しないドローンでも合法的に飛行できるよう指定された特定の区域です。コミュニティベースの団体(CBO)や教育機関がFAAに承認を申請して設置します。

## 要点

- FRIAは、Remote IDの機器を搭載していないドローンを飛行させてよい、地理的に定められた区域です。
- 飛行中は、ドローンも操縦者もずっとFRIAの境界内にいなければならず、操縦者は機体を目視内に保つ必要があります。
- 申請できるのはFAAが認めたコミュニティベースの団体と教育機関のみで、FAADroneZoneを通じて行います。個人の操縦者が単独でFRIAを作ることはできません。
- FRIAの承認には期限があり、取り消されることもあります。古い飛行場リストに頼らず、FAAの地図で確認してください。

## なぜ必要なのか

Remote IDが義務化されたことで、これを発信できないドローンにも、合法的に飛行を続けられる場所が必要になりました。FRIAはそれに対するFAAの答えで、承認された境界内では、Remote IDのないドローンの運用が認められます。規則は14 CFR Part 89のSubpart Cにあり、手続きはアドバイザリーサーキュラー(AC)89-3でFAAが説明しています。

お使いのドローンがRemote IDを発信できる場合(機体内蔵、またはブロードキャスト用モジュール経由)、FRIAは必要ありません。基本的な要件については[Remote ID要件の解説](/ja/guides/remote-id-requirements-explained)を参照してください。

## FRIAの仕組み

| ポイント | FAAの説明 |
|---|---|
| Remote IDなしで飛行できる人 | Remote ID機器のないドローンを、FRIA内に限って飛行させる場合 |
| 操縦者の位置 | ドローンも操縦者も、運用の全期間にわたってFRIAの境界内にいなければならないとFAAは明記しています |
| 目視 | Remote IDのないドローンは、目視内で飛行させなければなりません |
| 申請できる団体 | FAAが認めたコミュニティベースの団体、および教育機関(初等・中等学校、専門学校、短大・大学) |
| 申請先 | FAADroneZoneのFRIAサービスのオプション |
| 認定期間 | FAAの承認から48暦月。更新の申請は期限の120日前までに行う必要があります |
| 取り消し | 航空安全や公共の安全に関する懸念、虚偽または誤解を招く情報などを理由に、FAAがFRIAを取り消すことがあります |

申請者は、団体と権限を持つ代表者を明示し、正確な場所、区域の目的と必要性を記載し、飛行場について既存の合意書があればそれを添付する必要があります。FAAは、重なる空域の制限、他の航空機による空域の安全な利用、地上の安全、近隣の既存FRIAで必要が満たされないかどうかを考慮します(14 CFR 89.210および89.215)。

## 操縦者が知っておくべきこと

- FRIAは米国FAAの制度に固有のものです。他国に同様の制度があっても、名称や条件は異なります。
- FRIAの外では、米国の規則上、Remote IDのないドローンは飛行できません。まず自分の機体がRemote IDに対応しているか確認してください。
- FRIA内にいることで、他の空域の規則が免除されるわけではありません。FAAは、操縦者が自分の空域を理解し、必要な許可を得る責任を負うと説明しています。[米国の空域クラス解説](/ja/guides/understanding-us-airspace-classes)と[米国の規制ページ](/ja/regulations/us)を参照してください。
- FAAは、承認されたFRIAの場所をUAS Data Delivery Systemの対話型マップで公開しています。FRIAは申請した団体が運営しているため、そのクラブや飛行場にも自分で確認してください。

## よくある間違い

- 空き地やクラブの飛行場なら、どこでもFRIAだと思い込むこと。FAAが認めた区域だけが該当します。
- 境界の外に立って、境界の上空でドローンを飛ばすこと。操縦者も区域内にいなければなりません。
- FRIAを目視内飛行の規則の抜け道と考えること。目視は引き続き必要です。
- 認定が48か月で失効し、更新されなければ終了することを忘れること。以前FRIAだった場所が、今はそうでないこともあります。

## よくある質問

### FRIAは誰が設置できますか?
FAAが認めたコミュニティベースの団体と教育機関のみが申請できます。個人の操縦者は申請できませんが、FRIAを持つクラブに加入することはできます。

### ドローンがRemote IDに対応していれば、FRIAは必要ですか?
いいえ。FRIAはRemote IDを発信しないドローンのための制度です。発信するドローンには、通常のRemote ID要件が適用されます。

### FRIAの外で、Remote IDのないドローンを飛ばせますか?
FAAのFRIAのページで説明されているRemote ID規則では認められず、FRIA内で飛行させる必要があります。現行の規則や他の適合方法については、FAAのRemote IDのページで確認してください。

### 近くのFRIAはどうやって探せますか?
FAAのUAS Data Delivery Systemにある対話型のFRIAマップを使い、その後、その場所を運営する団体に連絡して、利用方法と規則を確認してください。
