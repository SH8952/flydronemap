ドローンにはメーカーが表示する最大風速耐性、つまりその風速でも機体が位置を保持できるとされる数値があります。機種選びや、今日の風が自分の機体の限界内かどうかを判断する際の参考として、主要機種のスペックを比較しました。

## 機種別 最大風速耐性

| メーカー | 機種 | 最大風速耐性 |
|---|---|---|
| DJI | Neo | 約29km/h(8m/s) |
| DJI | Mini 4K / Mini 3 / Mini 3 Pro / Mini 4 Pro | 約38km/h(10.7m/s、ビューフォート風力階級5) |
| DJI | Mini 5 Pro | 約43km/h(12m/s) |
| DJI | Air 2S | 約38km/h(10.7m/s、ビューフォート風力階級5) |
| DJI | Air 3 / Air 3S | 約43km/h(12m/s) |
| DJI | Mavic 3 Classic / Mavic 3 Pro | 約43km/h(12m/s) |
| DJI | Avata 2 | 約38km/h(10.7m/s、ビューフォート風力階級5) |
| DJI | Inspire 3 | 離着陸時 約43km/h(12m/s)、飛行中 約50km/h(14m/s) |
| Autel | EVO II Pro V3 | 離着陸時 約38km/h(10.7m/s)、巡航時 約43km/h(12m/s) |
| Autel | EVO IIIシリーズ | 約43km/h(12m/s) |
| Skydio | X10 | 最大突風対応 約46km/h(12.8m/s) |

*上記の数値は2026年10月3日にメーカー公式スペックページで確認した値です。以前この表でAir 3・Mavic 3シリーズ・Inspire 3を38km/h(10.7m/s)としていた記載と、AutelおよびSkydioの数値を修正しました。離着陸時と飛行中で値が異なる機種(Inspire 3、Autel EVO II Pro V3)は両方を記載しています。正確な数値はモデル改訂によって変わる場合があるため、購入・飛行前にメーカーの最新公式スペックページで確認してください。*

## 表示された数値をそのまま飛行限界と考えてはいけない理由

メーカーが表示する最大風速耐性は、管理された条件下で機体が姿勢を維持できる限界値であり、安定した映像や快適な飛行を保証する数値ではありません。この限界値に近い風では、バッテリー消耗が急激に増え、ジンバルの揺れや映像のブレが大きくなり、持続風にさらに突風が重なると一瞬で制御を失うリスクも高まります。

## 熟練パイロットが実際に使う安全マージン

経験豊富なパイロットの多くは、表示値の**60〜70%程度**を実質的な飛行上限としています。例えばDJI機体(38km/h等級)であれば、実際には23〜27km/h程度を超えたら飛行を再考する、という具合です。初心者はさらに保守的に、経験を積むまでは15〜20km/h以下での飛行をおすすめします。

## ダッシュボードの「お持ちの機種の風判定」の仕組み

FlyDroneMapのメインダッシュボードで上記の機種を選ぶと、現在の突風をその機種の公式最大風速と比較して判定します。突風が公式最大風速の**50%未満なら良好、50%以上で注意、70%以上で非推奨**と表示します。たとえば最大風速が約43km/h(12m/s)の機種なら、突風が約22km/hから注意、約30km/hから非推奨になります。離着陸時と飛行中で値が異なる機種は、低い方の値を基準にします。この判定は地表付近の突風に基づく参考情報で、空域や法規は考慮していません。

## 飛行前の確認事項

- 平均風速ではなく突風(gust)の数値を基準に判断してください。
- 自分の正確な機種名と最新の公式スペックをメーカーサイトで確認してください。
- このページの数値は参考用のまとめであり、安全判断の最終的な基準は常にメーカーの公式仕様です。
