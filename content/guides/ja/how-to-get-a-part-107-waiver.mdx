同じ週に2社がウェイバー申請を出すところを想像してください。1社は目視観測員のリレーでは現実的に見続けられない6マイル(約9.6km)のパイプライン点検ルートを飛ばす必要がある点検会社、もう1社は田舎のアクセス道路を走行中のトラックの荷台からドローンを発進させたいマッピングチームです。どちらの運航もFAAのPart 107ウェイバーなしでは認められず、どちらも申請の成否が安全性の説明にかかっている種類のものです。FAAは、運航上の危険を特定せずリスク低減策を提案していない申請は、実際の飛行がどれほど安全でも不承認にするとしています。

## 要点

- ウェイバーは、FAAが、その条件の下で運航を安全に行えると認めた場合に、証明書を持つリモートパイロットがPart 107の特定の規則(一覧は14 CFR 107.205にあります)から逸脱することを認めるものです。
- 申請は安全性の説明を軸に組み立てます。運航を説明し、免除する規則が通常抑えている危険を挙げ、自分の低減策がその機能をどう置き換えるかを示します。
- FAAは90日以内の判断を目標としていますが、時期は複雑さによって変わるとしているため、早めに申請し、申請の範囲は狭く絞ってください。
- 通常の夜間飛行と人の上空の飛行にはウェイバーはもう不要です。空港付近の空域の許可は別の手続きです。
- BVLOSは107.31のウェイバーで扱われてきましたが、FAAは別のBVLOS規則も提案しています。最新の状況はFAAで確認してください。

## ウェイバーが実際に許可するもの

14 CFR 107.200に基づき、FAAは、提案された運航がその証明書の条件の下で安全に行えると認めた場合に、ウェイバーの証明書を発行できます。申請には、運航の完全な説明と、安全に行えることを立証する根拠を含める必要があり、FAAは必要と考える制限を追加することがあります。保持者は、ウェイバーが指定する範囲でのみPart 107から逸脱でき、その中のすべての条件を守らなければなりません。

免除できる規則は、14 CFR 107.205に列挙されています。

| 条項 | 内容 |
|---|---|
| 107.25 | 移動中の車両または航空機からの運用 |
| 107.29(a)(2)および(b) | 夜間および市民薄明時の衝突防止灯 |
| 107.31 | 目視内飛行(VLOS) |
| 107.33 | 視覚補助者 |
| 107.35 | 複数の小型無人航空機の運用 |
| 107.37(a) | 進路を譲ること |
| 107.39 | 人の上空の運用 |
| 107.41 | 特定の空域での運用 |
| 107.51 | 運用上の制限(速度、高度、視程、雲との距離) |
| 107.145 | 移動中の車両の上空での運用 |

規則そのものに、2つの制限が書かれています。FAAは、報酬を得て他人の物を運ぶことを認める目的では、107.25または107.31のウェイバーを発行しません。一覧にない条項は、この手続きでは免除できません。

## まだウェイバーは必要か?夜間、人の上空、空域

何かを書き始める前に、自分のやりたいことが、すでに規則でカバーされていないか確認してください。

- 夜間飛行。FAAの条項別の評価情報には、規則の改正により、夜間の運用がウェイバーなしで認められると記されています。107.29に基づく通常の夜間飛行には、最近の訓練と、3法定マイル先から見える衝突防止灯が必要で、[Part 107の概要](/ja/guides/faa-part-107-explained)で説明しています。灯火の要件のウェイバーは、引き続き申請できます。
- 人や移動中の車両の上空の飛行。同じFAAの文書によれば、規則の改正により、4つのカテゴリーの制度を通じて、人の上空での運用がウェイバーなしで認められます。該当しない機体については、引き続きウェイバーを申請できます。
- 空港付近の空域。クラスB、C、D、または地表面のクラスEの空域で飛行するための許可は、[LAANCの解説](/ja/guides/what-is-laanc-and-why-it-matters)にあるとおり、LAANCまたはFAADroneZoneで申請します。107.41は免除可能な一覧に含まれていますが、FAAの評価文書によれば、飛行基準部門は107.41の申請を判断しません。複合的な運用では、ウェイバーの申請と、そのウェイバー番号を参照する別の空域の申請を提出します。申請の種類を間違えることは、初めての人がよくする間違いです。

## 申請方法

FAAのウェイバーのページには、3つの手順が示されています。免除したい規則を決め、ウェイバーの安全性の説明(運航、リスク、低減策)を書き、Aviation Safety Hubのアカウントから提出します。このページには、新しい申請はFAADroneZoneではなくAviation Safety Hubを使い、以前に提出したウェイバーはFAADroneZoneに残ると記されています。

FAAのユーザーガイドによれば、手順は次のとおりです。

1. アカウントを作成します。顧客のユーザータイプを選び、本人確認を含めてLogin.govに登録し、DOT/FAA MyAccessと連携させます。
2. 運用者の情報、提案する運航(機体の詳細、日付、場所の座標、説明)、運航に関する質問に記入します。回答に基づいて、適用される規則がシステムによって追加されます。
3. 安全性の説明を完成させ、補足資料を添付します。運用概念書(Concept of Operations)が推奨されており、地図、図、手順も添えます。
4. 申請が発行、不承認、または取り下げのいずれかで決着するまで、ダッシュボードで状況を追跡します。

FAAの資料にある役立つ制限として、ユーザーガイドは、開始日を少なくとも90日後に、終了日を開始から48か月以内にすることを推奨しています。FAAの申請の手引きによれば、申請は提出後に修正できず、FAAが追加情報を求めた場合は30日以内に回答しないと申請が取り下げられます。また、安全性の説明は15,000文字、補足資料は最大10点などの制限も示されているため、適用される数字は最新の申請フォームで確認してください。ウェイバーを申請するのにドローンの登録は必要ありませんが、運航の前には必ず登録しなければなりません。

## 審査に耐える安全性の根拠の作り方

申請は、何も問題が起きないことを証明するよう求めているわけではありません。免除する規則が通常抑えている具体的な危険を挙げ、自分の低減策がその機能を置き換えることを示すよう求めています。FAAのウェイバー安全性説明ガイドラインは、次の内容を求めています。

- 運航の詳細:座標と地図、最大高度、空域クラス、5マイル以内の空域、区域の種類(農村、人口密集地など)。
- 機体の詳細:種類と動力源、飛行時間、航続距離、速度、積載時の寸法と重量、ジオフェンスや係留などの封じ込めの方法、飛行終了のシステム。
- 要員:リモートパイロット・イン・コマンドの最低限の経験、乗員の人数、補助者と乗員の訓練、能力をどう試験するか、定期訓練。
- リスクと低減策:制限、技術、訓練、装備、要員、立入制限区域によって、「異常な状況でも」運航がどう安全に保たれるか。

FAAは、発行されたウェイバーの検索可能な一覧も公開しており、それぞれにPDFがリンクされています。自分が対象とする条項について認められたウェイバーを読むと、FAAが実際に付けた条件が分かります。

## 条項ごとにFAAが見る点

FAAの条項別の評価情報には、審査官が何を見るかが説明されています。例を挙げます。

| ウェイバー | 評価の焦点 |
|---|---|
| 107.25 移動中の車両 | 動的な環境の危険、視線を遮る障害物、注意をそらすもの、通信の途絶。通信途絶時の手順は、107.31への適合を保ち、人の上空の飛行を避けるものでなければなりません |
| 107.31 BVLOS | 高度、姿勢、動きの把握。航空機の探知と回避。視認性。乗員の知識。指令・制御リンク |
| 107.35 複数の機体 | 故障しても人や財産に不当な危険が及ばないような、運航場所や性能の基準。バッファーの例は、区域の端からの距離に対する最大高度の比が少なくとも1対1です |
| 107.51(a) 時速100マイル超 | たとえば立入制限によって、追加の危険が安全性を損なわないことを示すこと |
| 107.51(c)と(d) 視程または雲との距離の緩和 | ウェイバーはクラスGでのみ有効で、他のウェイバーや許可と組み合わせられません。審査官は、107.37に適合する方法と、操縦場所で測定した視程を求めます |

### BVLOSの詳細

107.31について、FAAの文書は、いくつかのアプローチを説明しています。VLOSの距離内で障害物の陰を飛行すること、視覚補助者の連鎖、空域の監視、技術による探知と回避です。この文書は、公表時点で、FAAは他の航空機を探知して回避するのに十分な技術を承認していないと述べ、指令・制御リンクは、干渉を許容する前提で運用されるFCC規則のPart 5またはPart 15のシステムに頼るべきではないとしています。視覚補助者については、人は、自分に向かってくるほとんどの航空機を約1.5法定マイルで、接線方向の経路の航空機を2〜2.5マイルで探知するのが一般に有効であるとし、評価者は、探知、通信、判断、操作にかかる時間に飛行した距離を、その数字から差し引きます。地上のレーダーにはFCCの認可が必要です。107.33のウェイバーは単独では発行されず、通常は107.31と組み合わせます。

FAAは、専用のBVLOS規則も提案しています。2025年8月6日付のページは、これを規則案として説明しており、ファクトシートは、リスクの低い運航には許可(permit)、リスクの高い運航には証明書(certificate)を想定していると説明しています。規則の策定は変わるため、これを前提に計画する前に、FAAのBVLOSのページで最新の状況を確認してください。

## 何か月も余計にかかってしまうミス

- 危険と低減策を書かないこと。FAAは、これだけで不承認になるとしています。
- ミッションに必要な範囲より広くウェイバーの範囲を設定すること。あらゆる場所での常時の権限よりも、ひとつのルート、高度帯、時間帯のほうが分析しやすくなります。
- 申請を同じ月で済む形式的な手続きと考えること。FAAは90日以内の判断に最善を尽くすとしていますが、複雑さがそれに影響します。
- 不測の事態への対応を書かないこと。通信途絶、GPSが使えない状況での航法、無許可の人が区域に入ることには、それぞれ名前のついた対応が必要です。
- 規則ですでに認められていることや、空域の許可をウェイバーとして申請するなど、種類の違う申請をすること。

## 実践チェックリスト

- 解除したい制限が107.205の一覧にあること、また現行の規則で通常の夜間飛行や人の上空の飛行としてすでにカバーされていないことを確認する。
- 空港付近の空域の利用は、別のLAANCまたは許可の手続きとして扱う。
- 申請は、ミッションに必要な範囲にぴったり絞る。
- 書き始める前に、FAAの発行済みウェイバーの一覧で、自分の条項について承認された申請を検索する。
- 通信途絶、GPSが使えない状況、無許可の人が入る場面に、それぞれ具体的な対応手順を用意する。
- 運航の少なくとも90日前に申請し、複雑な申請や複数の条項にまたがる申請ではさらに余裕を持つ。
- [FlyDroneMapのダッシュボード](/ja)と[米国の規制ページ](/ja/regulations/us)は、計画の参考にとどめる。認められたウェイバーは、記載された条件にあなたを拘束し、このサイトはFAAの許可の状況を確認も証明もしません。

## よくある質問

### Part 107ウェイバーには、どのくらい時間がかかりますか?

FAAは、提出から90日以内に承認または不承認とするよう最善を尽くすとしており、処理は複雑さによって変わるとしています。追加情報を求められた場合は、30日以内に回答する必要があります。

### 夜間に飛ばすのにウェイバーは必要ですか?

107.29の条件(最近の訓練と衝突防止灯)を満たす通常の夜間飛行には、必要ありません。灯火の要件など、条件を満たせない場合には、ウェイバーが関係します。

### ウェイバーがあれば、目視外で荷物を運べますか?

報酬を得て他人の物を運ぶ場合、107.25と107.31については認められません。規則は、その目的でこれらの条項のウェイバーは発行されないと定めています。

### どこで申請しますか?

FAAによれば、新しいウェイバーの申請は、Login.govのアカウントでAviation Safety Hubを通じて行います。以前の申請はFAADroneZoneに残っています。
